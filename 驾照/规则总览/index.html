signals · 信号灯与交警手势（教材级样板）

本节是全站「总览深度」样板：读完应能处理常见灯控路口，而不是只背「红停绿行」。

1. 先认路口形态（场景）

形态特征学车时要想到什么
十字路口两路正交，四向进口对向、邻向、行人过街同时存在；左转常与对向直行冲突
丁字路口三向，一路到头到头车无「直行穿出」，多为左转/右转；支路车常要让干路
斜交路口非直角交叉视线死角更大，更要降速；导向箭头可能不直觉
五叉 / 多路交叉≥5 个进口灯序复杂，必须严格看本进口、本车道对应的灯，不要抄邻车道
环岛 + 信号灯部分城市环岛入口/内部有灯以现场灯与标线为准；无灯时才按环岛让行惯例
进口车道数单排 / 双排 / 三排及以上排数↑ → 更常设导向车道与箭头灯；走错导向车道再变道易违法

单排：一个进口车道，灯通常管本方向全部车辆。 双排：常分「直行+右转」与「左转」，或「直行」与「左转」；务必看地面箭头。 三排及以上：常见左专用、直行、右专用；进入导向车道后应按箭头方向行驶，到停止线再想变道通常已晚。

2. 再认灯具形态（场景）

灯型长什么样管什么
圆形灯红黄绿圆点对本方向「未另设箭头灯」的通行方向有效；有箭头灯时，圆形灯与箭头灯分工见下
箭头灯红黄绿箭头只管箭头所指方向；箭头红 ≠ 其他方向也不能走
混合圆形 + 箭头并列/组合最易混：某一方向看箭头，另一方向看圆形；以本车道对应灯为准
横排灯水平排列读灯习惯从左到右；逻辑与竖排相同
竖排灯垂直排列常见上红下绿；逻辑不变
车道信号灯对单条车道只对本车道；邻道绿灯不能当成自己的
闪光警告（黄闪）黄灯闪烁提示注意，不等于放行特权；按让行/安全通行
人行横道灯行人红绿车让人：人行绿灯/闪时更要礼让；车灯与人灯可能不同步，以现场为准

3. 基本灯色含义（怎么走 / 不能怎么走 / 为什么）

红灯

  • 怎么走：在停止线后停车等待；已越过停止线且无法安全停下的，按现场与法规谨慎处理，但不得加速抢行。
  • 不能怎么走：闯过停止线继续通行；红灯时占用对向/人行横道；借「没车」抢行。
  • 为什么：红灯是时间上隔离冲突车流/行人的硬规则，靠自觉目测「有没有车」不可靠。

黄灯

  • 怎么走：已越过停止线的车辆可继续通过；未过线应停在线后（能安全停下时）。
  • 不能怎么走：看到黄灯加速冲过；在线前还能停却冲入。
  • 为什么：黄灯是「清空」过渡，不是「再抢两秒」。

绿灯

  • 怎么走：在确保安全、按导向车道与让行规则下通行；左转仍常要让对向直行与行人（视灯控与标线）。
  • 不能怎么走：绿灯就无视行人、非机动车；堵塞路口（进口绿灯但出口堵死仍顶进）。
  • 为什么：绿灯给的是「许可时机」，不是「免责特权」。

4. 圆形灯 × 箭头灯 × 车道（组合怎么走）

只有圆形灯（无箭头）

  • 本方向红：该进口受控方向一般不得越过停止线通行（具体以标志标线是否允许右转等为准，部分路口红灯可右转但必须让行，以现场标志为准）。
  • 本方向绿：可按车道箭头直行/转向，并礼让行人与优先方向。

只有箭头灯

  • 绿灯箭头：允许向箭头方向通行。
  • 红灯箭头：禁止该方向；其他方向若另有绿灯仍可能通行——例如左转红、直行绿时，直行可以、左转必须等。
  • 不能：看见邻方向箭头绿就跟着走；或「反正都是绿」不看箭头朝向。

混合（圆形 + 箭头）常见考法 1. 直行看圆形，左转看左转箭头（或相反，以灯板布局与车道对应关系为准）。 2. 圆形红 + 右转箭头绿：常表示可右转（仍须让行人与优先车辆）。 3. 圆形绿 + 左转箭头红：直行可，左转不可。 4. 怎么确认：看自己车头所在导向车道对应的那一组灯，不要抄旁边车道司机。

横排 vs 竖排：排列方式不改变含义；考的是颜色与箭头，不是灯的几何摆放。

5. 分路口类型怎么走（矩阵）

5.1 十字 · 双排/三排 + 混合灯（高频）

  • 场景：左专用道对着左转箭头；中间直行对着圆形或直行箭头；右侧右转车道可能全时或箭头控制。
  • 怎么走：提前读地面箭头 → 进对车道 → 停在停止线后看本车道灯 → 放行后先看行人与冲突车再走。
  • 不能：实线区变道插队；左转灯红却从直行道硬切左转；绿灯右转不看行人。
  • 为什么：多车道靠「空间分离（导向）」+「时间分离（灯）」同时工作，破坏任一环都冲突。

5.2 丁字路口

  • 场景：到头方向常是左右转；支路汇入。
  • 怎么走：确认有无禁止某转向；看本进口灯；到头车注意行人过街。
  • 不能：把丁字当十字强行「直行」闯入禁行或逆方向。
  • 为什么：几何上冲突点不同，错把灯序当十字会误判放行。

5.3 五叉 / 多路

  • 场景：一个绿灯可能只放某一股车流。
  • 怎么走：只信本进口灯与导向；慢速确认驶出口。
  • 不能：跟着前车不同方向走；在路口中央犹豫变道。
  • 为什么：冲突点数量随进口数上升，更依赖灯控与导向。

5.4 单排进口

  • 场景：一灯管多方向。
  • 怎么走：灯绿后再结合车道内位置与标志完成转向；注意对向与行人。
  • 不能：单排里随意左右抢位导致占错轨迹。

6. 交警手势（优先）

  • 怎么走：现场交警手势优先于信号灯；按手势停/行/左弯待转等。
  • 不能：灯是绿但手势停仍强行；或假装没看见。
  • 为什么：事故、管制、灯故障时需要人工接管冲突分离。
  • 后果：拒不服从交警指挥属违法，可罚记分，并显著推高事故与追责风险。

7. 违规后果与为何这样罚（常见口径）

下列为学习用「常见口径」，确切记分/罚款以现行《道路交通安全法》及相关规定、当地执行为准。

行为常见后果倾向为何这样处理
驾车闯红灯常记较高分并罚款；再犯累加；易负事故主责直接破坏时间隔离，对向车与行人按绿灯信任通行，冲突接近「必然」
黄灯抢行（不该过线却过）常按不按灯通行或相关违法查处黄灯本用于清空，抢行把过渡期变成碰撞期
不按导向车道通行罚款/记分（各地执行细节不同）破坏路口内预设轨迹，造成侧面碰撞
红灯右转未让行（在允许右转时）未礼让行人/优先车辆可罚，事故易主责「可转」≠「抢先」；行人绿灯信任度高
不服从交警手势违法处罚；情节严重可加重临时管制失效会导致整片路口瘫痪或连环事故
堵住路口（绿灯顶死）可能以违反路口通行规定等查处牺牲整网通行效率，制造二次堵塞与追尾

为什么罚得「看起来重」：灯控路口是城市冲突密度最高的地方之一；用记分提高违法成本，是为了让「图几秒」远小于「伤人/追责」的预期损失。

8. 自检清单（学完本节应能回答）

1. 三排车道，左转箭头红、圆形绿灯：你在左转道能不能过？直行道呢？ 2. 丁字到头，只有圆形红：你能不能当「没灯」拐进干路？ 3. 五叉路口邻道箭头绿、你的圆形红：能不能跟着邻道走？ 4. 灯绿但交警举手示意停：听谁的？ 5. 闯红灯除了罚款记分，事故责任上通常为什么不利？

signs · 标志（教材级）

读完应能：远远看见牌子先分清「禁令 / 指示 / 警告」，并知道常见牌在路口怎么走。

1. 先认三类外形（场景）

类型典型外形第一反应
禁令圆形红圈（可带斜杠）、倒三角（停车让行）等不能做 / 必须限制做
指示多蓝底白图案按这个方向/车道规则走
警告黄底黑边三角（部分变形）前方有风险，减速观察

为什么先认外形：考试与上路都靠快速分型。分错型会把「警告」当「禁止」吓停，或把「禁令」当「指示」硬闯。

2. 高频禁令（六问）

2.1 禁止驶入 vs 禁止通行

  • 场景：单行出口、施工封闭、错误匝道入口、大院门禁路。
  • 怎么走：禁止驶入 → 该方向车辆不得进入，绕行；禁止通行 → 该路段不对车辆开放。
  • 不能怎么走：倒车硬进、跟车闯、夜间无监控就闯。
  • 为什么：单向与封闭用于消除对向冲突或保护作业区。
  • 违规后果（常见口径）：逆行/不按禁令通行可罚记分；事故中易负主责。以现行规定与当地执行为准。
  • 为何这样罚：逆向与合法方向接近「对撞几何」，必须高成本震慑。

2.2 禁止转向（左 / 右 / 掉头）

  • 场景：路口进口、中央隔离开口、桥下掉头区。
  • 怎么走：按允许方向行驶；需转向则提前到可转路口。
  • 不能怎么走：实线区强行转；借非机动车道完成禁止转向。
  • 为什么：该转向会切开主冲突车流或压缩行人空间。
  • 违规后果：不按禁令/导向转向可罚；侧面碰撞风险高。
  • 为何这样罚：预先拆掉路口危险冲突点。

2.3 限速与解除限速

  • 场景：路段起点、弯道/学校/隧道前、高速分区限速。
  • 怎么走：从标志起按最高时速控制；见解除或新限速牌再调整。
  • 不能怎么走：「路况好就超一点」；完全跟流超速。
  • 为什么：限速按视距、冲突、脆弱交通参与者密度标定。
  • 违规后果：超速按幅度处罚，严重超速更重（档位以现行规定为准）。
  • 为何这样罚：动能随速度显著上升，超速把「可刹停」变成「不可刹停」。

2.4 停车让行 vs 减速让行

  • 场景：支路进干路、视线不良交叉口。
  • 怎么走：停车让行 → 先停稳再观察后进入；减速让行 → 降速观察，有优先车则停让。
  • 不能怎么走：停车让行下「慢滑不停车」；把减速让行当可抢行。
  • 为什么：停车让行用于冲突更危险或视线更差处。
  • 违规后果：不让行致事故常负主责；也可单独查处。
  • 为何这样罚：支路对干路速度差易造成侧面重创。

2.5 禁止鸣喇叭 / 禁止停车 / 禁止长时停车

  • 场景：学校医院居民区；禁停与临停分区。
  • 怎么走：禁鸣区不鸣；禁停不占；临停按标志文字且不碍通行。
  • 不能怎么走：用双闪冒充合法停；禁停点上下客占道。
  • 为什么：噪声与占道损害安宁与通行容量。
  • 违规后果：违停可拖移并处罚；禁鸣可罚。
  • 为何这样罚：路权稀缺，占道把公共空间私人化。

3. 高频指示（六问）

  • 场景：车道方向、单行、人行横道、立交指引。
  • 怎么走：按蓝底箭头进入正确车道/匝道；横道处减速礼让。
  • 不能怎么走：把指示箭头当成可任意插队变道的许可。
  • 为什么：指示把车流导入正确空间分离方案。
  • 违规后果：走错导向后再压实线变道，常叠加违法。
  • 为何这样罚：维护路网预设分离，降低路口乱序。

4. 高频警告（六问）

  • 场景：交叉口、急弯、易滑、注意儿童/行人、施工、铁道。
  • 怎么走：提前减速、扩大观察、准备制动。
  • 不能怎么走：以为「不是禁令就可以不减速」。
  • 为什么：警告标的是事故高发几何或环境。
  • 违规后果：未降速致事故时，警告成为「应预见」证据之一。
  • 为何这样罚：提高对可预见风险疏忽的责任份额，保护弱势者。

5. 自检

1. 红圈禁令与蓝底指示同时出现，先服从哪类硬约束？ 2. 停车让行牌前能否「慢滑不停车」？ 3. 「注意儿童」路段超速后事故，责任评价会如何倾向？

markings · 道路标线（教材级）

标线是画在地上的法规，与 #signs #signals 一起用。

1. 颜色与虚实（总表）

标线场景怎么走不能怎么走为什么
同向白虚线多车道同向确认安全可变更车道不打灯、逼车变道虚线=有条件转换空间
同向白实线路口导向段、部分隧道保持车道压实线变道超车冲突点密或视距差
黄虚线对向可借道路段按规定与安全条件越线盲目占对向对向冲突有条件开放
黄实线/双黄对向严格分离不得轧线驶入对向「超一下就回来」对向碰撞致死率高
导向箭头进口车道按箭头方向行驶进错道后在实线区硬切分离左转/直行冲突
停止线灯控/让行前车头停线后压线停、越线等灯保护冲突区清空
导流线渠化三角区两侧绕行轧线取直不是可行车道
人行横道过街处减速礼让行人行人在途加速鸣笛保护弱势使用者

2. 与灯、牌配合

  • 灯控+停止线：红灯停线后（见 #signals）。
  • 导向箭头+白实线：进入后基本锁定方向。
  • 导流线+禁止驶入：轧线近似闯入隔离区。

3. 违规后果与为何罚（常见口径）

行为常见后果倾向为何这样罚
轧实线变道可罚；事故易负主要责任破坏预设分离
轧导流线可按不按规定车道等查处保护缓冲空间
压停止线等红灯视情节查处侵占清空与行人空间
人行横道不礼让可罚记分；事故重责风险高行人信任横道规则

4. 自检

1. 停止线前白实线上，能否从直行道插到左转道？ 2. 导流线能否当宽路抄近路？ 3. 双黄线超车与白虚线变道，危险差在哪？

lights · 灯光与喇叭（教材级）

1. 灯具与场景

灯光主要场景怎么走不能怎么走
近光有路灯、会车、尾随默认照明该近光时开远光晃人
远光无灯照明不良会车/近距尾随改近光；可交替示意市区一路远光
雾灯雾尘低能见度按规定开，恢复后关晴夜开后雾灯晃后车
转向灯变道转弯靠边起步先灯后动边变道边打灯
危险报警闪光灯故障事故严重拥堵警示按规定开并设警示标志违停「有双闪就合法」

2. 典型场景六问

2.1 夜间会车

  • 场景：对向来车接近。
  • 怎么走：改近光，减速靠右。
  • 不能怎么走：互飙远光。
  • 为什么：眩目让双方短暂失明。
  • 违规后果：可查处；眩目肇事常认定操作不当。
  • 为何这样罚：禁止把照明变成攻击性眩光。

2.2 隧道与雨雾

  • 场景：亮度突变、水雾散射。
  • 怎么走：进隧道开灯；雨雾近光+雾灯（按条件），降速增距。
  • 不能怎么走：隧道远光乱射；雾天只开双闪高速开。
  • 为什么：瞳孔适应慢；远光在雾中散射更瞎。
  • 违规后果：不当灯光+超速叠加事故责任。
  • 为何这样罚：低能见度必须降风险而非「照更亮硬冲」。

2.3 喇叭

  • 场景：提醒危险；禁鸣区、夜间。
  • 怎么走：短促提醒；禁鸣与夜间遵守标志与规定。
  • 不能怎么走：堵车连续狂按发泄。
  • 为什么：喇叭是告警不是路权。
  • 违规后果：违规鸣号可罚。
  • 为何这样罚：抑制噪声伤害与挑衅性驾驶。

3. 自检

1. 城区有路灯，对向来车时能否继续远光？ 2. 双闪能否替代高速车后三角警示牌？ 3. 禁鸣标志下「轻轻按一下」是否一定合法？

speed · 速度、跟车、超车、会车（教材级）

1. 限速

场景怎么走不能怎么走为什么
有限速标志从标志起守最高限速「超一点没事」上限不是建议巡航+20
雨雾冰雪限速下再降速限速内仍高速贴车附着与视距下降
学校弯道村庄提前减速进弯才急刹视距与行人密度
  • 违规后果：超速按幅度处罚，严重超速更重（以现行规定为准）。
  • 为何这样罚：速度决定制动距离与碰撞能量。

2. 跟车

  • 场景：拥堵、高速、夜间。
  • 怎么走：保持前车急刹时能停下的距离；车速越高间距越大。
  • 不能怎么走：贴保险杠、频繁别车。
  • 为什么：反应时间+制动距离是物理硬约束。
  • 违规后果：追尾通常后车责任更重（视案情）。
  • 为何这样罚：督促留余量，降低连环追尾。

3. 不得超车的高频情形

前车正在左转/掉头、对向有会车可能、禁止超车标志或实线、交叉路口、人行横道、铁路道口、急弯陡坡窄桥、隧道等（以法规与现场为准）。

  • 怎么走：跟驰等待，或在允许路段完整超车后返回。
  • 不能怎么走：实线区强超、路口超车。
  • 为什么：视距不足或冲突点集中。
  • 违规后果：违法超车可罚记分；事故易主责。
  • 为何这样罚：超车主动制造冲突，必须高门槛。

4. 会车

  • 怎么走：减速靠右，注意路肩非机动车与障碍。
  • 不能怎么走：抢窄路、会车远光。
  • 为什么：共享宽度时速度差易刮擦或坠险。
  • 违规后果：会车不当致事故按过错认定。
  • 为何这样罚：迫使在窄空间选择低风险策略。

5. 自检

1. 限速 80 开到 100，制动距离如何定性变化？ 2. 实线区「超一下」为何不行？ 3. 前车右转灯亮，能否从其右侧高速超越？

yield · 路口通行与让行（教材级）

有灯先看 #signals；本节管无灯、灯控外让行，以及灯绿仍须让的情形。

1. 场景分类

场景怎么走不能怎么走为什么
无灯交叉口减速观察；按让行规则与干支关系谁胆大谁先无时间隔离就必须礼让
停车/减速让行标志见 #signs滑行抢先支路让干路
转弯 vs 直行冲突时转弯让直行左转抢对向直行直行更难避让
环岛让岛内车；出岛打灯岛内突然变道逼车环形优先减少冲突
人行横道/学校减速礼让鸣笛催行人保护弱势
出口堵死能通过才进入绿灯顶死路口保护路网效率

2. 事故责任倾向（学习用）

未让行、未减速、侵道转弯导致碰撞，通常对未履行让行义务一方更不利；具体由交警认定。

3. 后果与为何罚

不按规定让行、人行横道不礼让等可罚记分（以现行规定为准）。目的：提高「抢一秒」成本，保护行人与优先方向信任。

4. 自检

1. 灯绿左转，对向直行也绿，谁先？ 2. 进环岛与岛内车，谁让谁？ 3. 出口堵死时进口绿灯能否继续顶入？

penalty · 处罚、记分与证件（教材级）

不背过期分值表。确切记分/罚款/程序以现行规定与当地车管所/交警为准。

1. 记分制度

  • 场景：违法查处、记分周期、满分处理。
  • 怎么走：关注记分；满分后按规定学习考试处理，不得带满分继续开。
  • 不能怎么走：无视满分通知仍驾驶。
  • 为什么：渐进剥夺高风险驾驶人上路权。
  • 违规后果：满分未处理仍驾驶属更严重违法。
  • 为何这样罚：防止「罚单当买路钱」累积危险行为。

2. 红线违法

行为为什么严禁后果倾向
酒驾/醉驾反应判断受损行政直至刑事；事故责任极重
毒驾认知失控严惩
伪造变造牌证破坏监管严惩并影响办证
肇事逃逸贻误抢救严惩；民刑风险叠加
替考作弊放行不合格驾驶人违法；本站拒绝相关建议

3. 证件与审验

  • 怎么走：按期审验换证体检；实习期限制以现行规定为准。
  • 不能怎么走：过期证驾驶、出借给无资格者。
  • 为什么：证件是资格证明。
  • 违规后果：无证/过期驾驶严惩。
  • 为何这样罚：切断无资格驾驶。

4. 自检

1. 记分满分次日能否照常上路？ 2. 「喝一点觉得没事」能否开？ 3. 某违法记几分应以什么为准？

subject4 · 科目四：文明与应急（教材级）

1. 安全带与安全装置

  • 场景：短途、后排、有气囊车型。
  • 怎么走：上车先系；儿童用合格约束装置；气囊辅助。
  • 不能怎么走：短途不系、儿童怀抱、气囊代替安全带。
  • 为什么：碰撞毫秒级约束决定是否撞击内饰。
  • 违规后果：不系可罚；事故伤害更重。
  • 为何这样罚：降低可预防的二次碰撞伤害。

2. 紧急情况（爆胎、制动异常等）

  • 怎么走：握稳方向、松油、缓刹（视情况）、开危险报警闪光灯、逐步靠边至安全处。
  • 不能怎么走：猛打方向、突然手刹甩尾、停行车道修车。
  • 为什么：突变时稳车优先于「立刻停死」。
  • 违规后果：失当操作可致翻车/连环撞。
  • 为何这样罚：引导故障车离开高暴露位置。

3. 天气夜间高速事故（原则）

能见度差→减速增距；会车近光；应急车道紧急才用；事故先警示再报警，不逃逸、不二次伤害。细节见各课。

4. 自检

1. 有气囊能否不系安全带？ 2. 高速故障能否停行车道「先看看」？ 3. 事故后站车道中间拍照是否合适？

exam-prep · 考前材料与流程（教材级）

1. 材料

  • 场景：各科考场入场。
  • 怎么走：按本地通知带齐身份证、预约/准考凭证等；头晚与出发前核对。
  • 不能怎么走：借用他人证件、缺材料硬闯。
  • 为什么：身份与资格核验是公正底线。
  • 违规后果：无法入场或取消资格；伪造材料违法。
  • 为何这样罚：防止不合格者混入持证队伍。

2. 状态与时间

  • 怎么走：保证睡眠；提前出发；配合安检排队。
  • 不能怎么走：通宵刷题、酒后应考、迟到纠缠。
  • 为什么：疲劳与情绪直接抬高操作失误率。
  • 违规后果：状态不佳易不合格；酒后则违法。
  • 为何这样罚：考试也是安全场景，不是闯关游戏。

拒绝替考、作弊、买分。 本站不提供任何相关建议。作弊把不合格驾驶人放上路，风险转嫁全社会。
