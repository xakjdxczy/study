signals · 信号灯与交警手势（教材级样板）

本节是全站「总览深度」样板：读完应能处理常见灯控路口，而不是只背「红停绿行」。

1. 先认路口形态（场景）

形态特征学车时要想到什么
十字路口两路正交，四向进口对向、邻向、行人过街同时存在；左转常与对向直行冲突
丁字路口三向，一路到头到头车无「直行穿出」，多为左转/右转；支路车常要让干路
斜交路口非直角交叉视线死角更大，更要降速；导向箭头可能不直觉
五叉 / 多路交叉≥5 个进口灯序复杂，必须严格看本进口、本车道对应的灯，不要抄邻车道
环岛 + 信号灯部分城市环岛入口/内部有灯以现场灯与标线为准；无灯时才按环岛让行惯例
进口车道数单排 / 双排 / 三排及以上排数↑ → 更常设导向车道与箭头灯；走错导向车道再变道易违法

单排：一个进口车道，灯通常管本方向全部车辆。 双排：常分「直行+右转」与「左转」，或「直行」与「左转」；务必看地面箭头。 三排及以上：常见左专用、直行、右专用；进入导向车道后应按箭头方向行驶，到停止线再想变道通常已晚。

2. 再认灯具形态（场景）

灯型长什么样管什么
圆形灯红黄绿圆点对本方向「未另设箭头灯」的通行方向有效；有箭头灯时，圆形灯与箭头灯分工见下
箭头灯红黄绿箭头只管箭头所指方向；箭头红 ≠ 其他方向也不能走
混合圆形 + 箭头并列/组合最易混：某一方向看箭头，另一方向看圆形；以本车道对应灯为准
横排灯水平排列读灯习惯从左到右；逻辑与竖排相同
竖排灯垂直排列常见上红下绿；逻辑不变
车道信号灯对单条车道只对本车道；邻道绿灯不能当成自己的
闪光警告（黄闪）黄灯闪烁提示注意，不等于放行特权；按让行/安全通行
人行横道灯行人红绿车让人：人行绿灯/闪时更要礼让；车灯与人灯可能不同步，以现场为准

3. 基本灯色含义（怎么走 / 不能怎么走 / 为什么）

红灯

  • 怎么走：在停止线后停车等待；已越过停止线且无法安全停下的，按现场与法规谨慎处理，但不得加速抢行。
  • 不能怎么走：闯过停止线继续通行；红灯时占用对向/人行横道；借「没车」抢行。
  • 为什么：红灯是时间上隔离冲突车流/行人的硬规则，靠自觉目测「有没有车」不可靠。

黄灯

  • 怎么走：已越过停止线的车辆可继续通过；未过线应停在线后（能安全停下时）。
  • 不能怎么走：看到黄灯加速冲过；在线前还能停却冲入。
  • 为什么：黄灯是「清空」过渡，不是「再抢两秒」。

绿灯

  • 怎么走：在确保安全、按导向车道与让行规则下通行；左转仍常要让对向直行与行人（视灯控与标线）。
  • 不能怎么走：绿灯就无视行人、非机动车；堵塞路口（进口绿灯但出口堵死仍顶进）。
  • 为什么：绿灯给的是「许可时机」，不是「免责特权」。

4. 圆形灯 × 箭头灯 × 车道（组合怎么走）

只有圆形灯（无箭头）

  • 本方向红：该进口受控方向一般不得越过停止线通行（具体以标志标线是否允许右转等为准，部分路口红灯可右转但必须让行，以现场标志为准）。
  • 本方向绿：可按车道箭头直行/转向，并礼让行人与优先方向。

只有箭头灯

  • 绿灯箭头：允许向箭头方向通行。
  • 红灯箭头：禁止该方向；其他方向若另有绿灯仍可能通行——例如左转红、直行绿时，直行可以、左转必须等。
  • 不能：看见邻方向箭头绿就跟着走；或「反正都是绿」不看箭头朝向。

混合（圆形 + 箭头）常见考法 1. 直行看圆形，左转看左转箭头（或相反，以灯板布局与车道对应关系为准）。 2. 圆形红 + 右转箭头绿：常表示可右转（仍须让行人与优先车辆）。 3. 圆形绿 + 左转箭头红：直行可，左转不可。 4. 怎么确认：看自己车头所在导向车道对应的那一组灯，不要抄旁边车道司机。

横排 vs 竖排：排列方式不改变含义；考的是颜色与箭头，不是灯的几何摆放。

5. 分路口类型怎么走（矩阵）

5.1 十字 · 双排/三排 + 混合灯（高频）

  • 场景：左专用道对着左转箭头；中间直行对着圆形或直行箭头；右侧右转车道可能全时或箭头控制。
  • 怎么走：提前读地面箭头 → 进对车道 → 停在停止线后看本车道灯 → 放行后先看行人与冲突车再走。
  • 不能：实线区变道插队；左转灯红却从直行道硬切左转；绿灯右转不看行人。
  • 为什么：多车道靠「空间分离（导向）」+「时间分离（灯）」同时工作，破坏任一环都冲突。

5.2 丁字路口

  • 场景：到头方向常是左右转；支路汇入。
  • 怎么走：确认有无禁止某转向；看本进口灯；到头车注意行人过街。
  • 不能：把丁字当十字强行「直行」闯入禁行或逆方向。
  • 为什么：几何上冲突点不同，错把灯序当十字会误判放行。

5.3 五叉 / 多路

  • 场景：一个绿灯可能只放某一股车流。
  • 怎么走：只信本进口灯与导向；慢速确认驶出口。
  • 不能：跟着前车不同方向走；在路口中央犹豫变道。
  • 为什么：冲突点数量随进口数上升，更依赖灯控与导向。

5.4 单排进口

  • 场景：一灯管多方向。
  • 怎么走：灯绿后再结合车道内位置与标志完成转向；注意对向与行人。
  • 不能：单排里随意左右抢位导致占错轨迹。

6. 交警手势（优先）

  • 怎么走：现场交警手势优先于信号灯；按手势停/行/左弯待转等。
  • 不能：灯是绿但手势停仍强行；或假装没看见。
  • 为什么：事故、管制、灯故障时需要人工接管冲突分离。
  • 后果：拒不服从交警指挥属违法，可罚记分，并显著推高事故与追责风险。

7. 违规后果与为何这样罚（常见口径）

下列为学习用「常见口径」，确切记分/罚款以现行《道路交通安全法》及相关规定、当地执行为准。

行为常见后果倾向为何这样处理
驾车闯红灯常记较高分并罚款；再犯累加；易负事故主责直接破坏时间隔离，对向车与行人按绿灯信任通行，冲突接近「必然」
黄灯抢行（不该过线却过）常按不按灯通行或相关违法查处黄灯本用于清空，抢行把过渡期变成碰撞期
不按导向车道通行罚款/记分（各地执行细节不同）破坏路口内预设轨迹，造成侧面碰撞
红灯右转未让行（在允许右转时）未礼让行人/优先车辆可罚，事故易主责「可转」≠「抢先」；行人绿灯信任度高
不服从交警手势违法处罚；情节严重可加重临时管制失效会导致整片路口瘫痪或连环事故
堵住路口（绿灯顶死）可能以违反路口通行规定等查处牺牲整网通行效率，制造二次堵塞与追尾

为什么罚得「看起来重」：灯控路口是城市冲突密度最高的地方之一；用记分提高违法成本，是为了让「图几秒」远小于「伤人/追责」的预期损失。

8. 自检清单（学完本节应能回答）

1. 三排车道，左转箭头红、圆形绿灯：你在左转道能不能过？直行道呢？ 2. 丁字到头，只有圆形红：你能不能当「没灯」拐进干路？ 3. 五叉路口邻道箭头绿、你的圆形红：能不能跟着邻道走？ 4. 灯绿但交警举手示意停：听谁的？ 5. 闯红灯除了罚款记分，事故责任上通常为什么不利？

signs · 标志（教材级）

读完应能：第一眼分清禁令/指示/警告/指路，并处理「标志+辅助牌」「标志与标线同时出现」的高频组合。

1. 大类与外形编码（形态矩阵）

大类外形第一眼含义总开关典型例子
禁令红圈（可斜杠）、倒三角等不能做 / 必须限制做禁止驶入、禁转、限速、停车让行
指示多蓝底白图案按此方向/车道规则走直行/转弯车道、单行、人行横道
警告黄底黑边三角（可变形）前方风险，减速观察交叉口、急弯、注意儿童/行人
指路多绿/蓝底地名方向路径指引地点距离、立交出入口
辅助标志附在主标志下的白底黑字牌限定时间/车种/方向/距离「货车」「7–9时」「向前 100 m」

为什么先认外形：考试与上路都靠亚秒级分型；分错型会闯禁令或忽视警告。

2. 高频禁令个案（每类六问）

2.1 禁止驶入 / 禁止通行

  • 场景：单行出口、施工封闭、错误匝道、大院门禁路。
  • 怎么走：该方向不得进入，绕行至允许入口。
  • 不能怎么走：倒车硬进、跟车闯、夜间闯。
  • 为什么：消除对向冲突或保护封闭区。
  • 违规后果（常见口径）：可罚记分；事故易负主责。以现行《记分管理办法》与当地执行为准。
  • 为何这样罚：逆向接近对撞几何，必须高成本震慑。

2.2 禁止转向 / 禁止掉头 / 禁止超车

  • 场景：路口进口、中央隔离开口、桥下、实线路段。
  • 怎么走：按允许方向；超车等待虚线或解除禁超路段。
  • 不能怎么走：实线强转强超；借非机动车道完成禁止动作。
  • 为什么：预先拆掉高危冲突点。
  • 违规后果：可罚；路口侧面碰撞责任风险高。
  • 为何这样罚：抑制「图几秒」切开主车流。

2.3 限速 / 解除限速

  • 场景：路段起点、弯道学校隧道前、高速分区。
  • 怎么走：从标志起守最高限速；见解除或新限速再调。
  • 不能怎么走：「超一点没事」、完全跟流超速。
  • 为什么：限速按视距与冲突密度标定。
  • 违规后果：超速按幅度处罚，严重超速更重（档位查《记分管理办法》原文）。
  • 为何这样罚：速度抬高碰撞能量与制动距离。

2.4 停车让行 / 减速让行

  • 场景：支路进干路、视线不良交叉口。
  • 怎么走：停车让行须停稳再观察进入；减速让行须降速，有优先车则停让。
  • 不能怎么走：停车让行「慢滑不停车」；抢行。
  • 为什么：支路对干路速度差致命。
  • 违规后果：不让行致事故常负主责；可查处。
  • 为何这样罚：强迫支路车交出优先权。

2.5 禁止鸣喇叭 / 禁止停车 / 禁止长时停车

  • 场景：学校医院居民区；路段禁停与临停分区。
  • 怎么走：禁鸣不鸣；禁停不占；临停按辅助牌且不碍通行。
  • 不能怎么走：双闪冒充合法停；禁停上下客。
  • 为什么：噪声与占道损害安宁与通行容量。
  • 违规后果：违停可拖移并处罚；禁鸣可罚。
  • 为何这样罚：路权稀缺，占道私人化公共空间。

3. 指示 / 警告 / 指路（组合要点）

  • 指示：蓝底箭头引导空间分离；进错导向车道后在实线区硬切会叠加违法。
  • 警告：不是禁令，但「应预见」；未降速事故中常成不利证据。
  • 指路：解决「去哪」，不替代禁令。

4. 标志 + 辅助牌；标志与标线同时出现

  • 组合怎么走：先读主标志，再读辅助牌的时间/车种/方向限定；在限定范围内遵守。
  • 冲突时：不得自行脑补谁优先；以现场交警指挥与法规适用为准，有疑问按更安全、更限制性的理解减速观察并择机安全处置。
  • 不能怎么走：只看辅助牌忽略主禁令；或「线能走就当标志无效」。

5. 自检

1. 红圈禁令与蓝底指示同时出现，先服从哪类硬约束？ 2. 停车让行牌前能否慢滑不停车？ 3. 辅助牌写「货车」时，小型客车是否受该禁令约束？

markings · 道路标线（教材级）

标线是画在地上的法规。形态矩阵：线型 × 场景 × 与灯/牌组合。

1. 线型形态矩阵

线型场景怎么走不能怎么走为什么
白虚线同向多车道路段打灯观察后可变道不观察逼车变道有条件转换空间
白实线路口导向段、部分隧道/桥保持车道压实线变道超车冲突点密或视距差
黄虚线对向可借道路段按规定与安全条件越线盲目占对向对向冲突有条件开放
黄实线 / 双黄线对向严格分离不得轧线驶入对向「超一下就回」对向碰撞致死率高
导向箭头进口车道按箭头方向行驶进错后在实线区硬切分离左转/直行冲突
停止线灯控/让行前车头停线后压线停、越线等灯保护冲突区清空
让行线支路让行与让行标志配套停/减速当减速带轧过不管落实让行义务
导流线渠化三角/斑马纹区两侧绕行轧线取直不是可行车道
人行横道过街处减速礼让行人在途加速鸣笛保护弱势
网状线易堵塞交叉口无空当不进入绿灯顶进堵死保整网效率
边缘线车行道边缘在线内行驶长期骑线占应急/路肩（视道路）廓清可行空间
公交专用线设公交专用路段非允许时段/车种勿占当普通车道穿行保障公交路权

2. 组合：标线 × 标志 × 灯

  • 导向箭头 + 白实线 + 红灯：进错道也不能压实线乱切；红灯停停止线后（见 #signals）。
  • 导流线 + 禁止驶入：轧导流≈闯入隔离。
  • 人行横道 + 灯：车灯与人灯可能不同步，以让行为安全底线。

3. 罚则与罚因（常见口径）

行为常见后果倾向为何这样罚

2. 场景六问（高频）

2.1 夜间会车 / 尾随

  • 场景：对向来车、近距离跟随前车。
  • 怎么走：改近光；减速靠右。
  • 不能怎么走：互飙远光、贴车远光。
  • 为什么：远光造成眩目，双方短暂失明。
  • 违规后果：可查处；眩目肇事常认定操作不当。
  • 为何这样罚：禁止把照明变成攻击性眩光。

2.2 隧道 / 雨雾雪沙尘

  • 场景：亮度突变、散射严重。
  • 怎么走：进隧道开灯；低能见度用近光+雾灯（按条件），降速增距。
  • 不能怎么走：隧道远光乱射；雾天只开双闪高速开。
  • 为什么：瞳孔适应慢；远光在雾中散射更瞎。
  • 违规后果：不当灯光叠加超速，事故责任加重。
  • 为何这样罚：低能见度必须降风险。

2.3 路口示意与故障停车

  • 场景：无灯路口示意、故障临停。
  • 怎么走：可用交替远近光示意（按场景）；故障开危险报警闪光灯并按规定设警示标志。
  • 不能怎么走：用双闪代替合法停车位置。
  • 为什么：警示是为了被看见，不是赋予路权。
  • 违规后果：不按规定设置警示引发二次事故责任重。
  • 为何这样罚：二次事故伤害往往更惨。

2.4 喇叭

  • 场景：提醒危险；禁鸣区、夜间。
  • 怎么走：短促提醒；禁鸣与夜间遵守标志与规定。
  • 不能怎么走：连续狂按发泄。
  • 为什么：喇叭是告警不是路权。
  • 违规后果：违规鸣号可罚。
  • 为何这样罚：抑制噪声与挑衅驾驶。

3. 自检

1. 城区有路灯，对向来车时能否继续远光？ 2. 双闪能否替代高速车后三角警示牌？ 3. 禁鸣标志下「轻轻按一下」是否一定合法？

speed · 速度、跟车、超车、会车（教材级）

1. 道路与天气形态矩阵

维度至少覆盖怎么走要点
道路城市道路、普通公路、高速公路；同向 1/2/3+ 车道按限速标志与车道规则；车道越多越要规范变道
天气晴、雨、雾、冰雪、低能见度限速下再降速；能见度越低间距越大
行为守限速、安全车距、超车、会车见下列分节

2. 限速（六问）

  • 场景：有限速标志路段、分区限速、弯道学校隧道前。
  • 怎么走：从标志起守最高限速；情况变差再降。
  • 不能怎么走：「超一点没事」、完全跟流超速。
  • 为什么：限速按视距与冲突标定。
  • 违规后果：超速按幅度处罚，严重超速更重——具体档位必须查《记分管理办法》原文。
  • 为何这样罚：速度抬高碰撞能量。

3. 跟车（六问）

  • 场景：拥堵、高速车流、夜间。
  • 怎么走：保持前车急刹时能停住的距离；车速越高间距越大。
  • 不能怎么走：贴保险杠、频繁别车。
  • 为什么：反应时间+制动距离是硬约束。
  • 违规后果：追尾通常后车责任更重（视案情）。
  • 为何这样罚：督促留余量，降连环追尾。

4. 不得超车清单（高频）

前车正在左转/掉头、对向有会车可能、禁止超车标志或实线、交叉路口、人行横道、铁路道口、急弯陡坡窄桥、隧道等（以《实施条例》与现场为准）。

  • 怎么走：跟驰等待；在允许路段完整超车后返回。
  • 不能怎么走：实线强超、路口超车。
  • 为什么：视距不足或冲突点集中。
  • 违规后果：违法超车可罚记分；事故易主责。
  • 为何这样罚：超车主动制造冲突，必须高门槛。

5. 会车（六问）

  • 场景：两车交会、窄路、有障碍一侧。
  • 怎么走：减速靠右；注意非机动车与路肩。
  • 不能怎么走：抢窄路、会车远光。
  • 为什么：共享宽度时速度差易刮擦/坠险。
  • 违规后果：会车不当致事故按过错认定。
  • 为何这样罚：迫使窄空间选低风险策略。

6. 自检

形态怎么走要点不能怎么走

2. 规则矩阵（六问）

2.1 转弯让直行（冲突时）

  • 场景：同绿灯或无灯，左转与对向直行交叉；右转与行人冲突。
  • 怎么走：直行与行人优先时等待。
  • 不能怎么走：抢绿左转；右转贴行人穿过。
  • 为什么：直行快、行人无防护。
  • 违规后果：未让行碰撞易主责；横道不礼让可罚记分（查现行规定）。
  • 为何这样罚：保护高暴露道路使用者。

2.2 让行标志/标线

见 #signs #markings。停车让行必须停稳。

2.3 行人优先场景

  • 场景：人行横道、学校区域。
  • 怎么走：减速礼让，禁鸣催促。
  • 不能怎么走：抢行人空隙加速。
  • 为什么：行人无防护。
  • 违规后果：可罚；事故重责风险高。
  • 为何这样罚：维护横道信任。

2.4 绿灯但仍堵

  • 场景：下游堵死。
  • 怎么走：能过清才进入。
  • 不能怎么走：顶进堵住横线。
  • 为什么：堵冲突区使信号失效。
  • 违规后果：可查处；诱发连环碰。
  • 为何这样罚：保路网效率。

penalty · 处罚、记分与证件（教材级）

禁止背口口相传的分值表。任何具体记分/罚款数字，必须以《记分管理办法》《道交法》等现行官方文本为准；下文只讲制度结构、红线与查阅方法。

1. 制度形态矩阵（必须穷举）

2. 高频违法类型（六问 · 分值查原文）

2.1 闯红灯 / 不按信号通行

  • 场景：灯控路口、箭头灯、车道信号灯（见 #signals）。
  • 怎么走：停停止线后；看本车道灯；手势优先。
  • 不能怎么走：借「没车」抢行、抢黄灯冲线。
  • 为什么：破坏时间隔离，对向与行人按绿灯信任通行。
  • 违规后果：记分与罚款档位以《记分管理办法》原文为准；事故中常极不利。
  • 为何这样罚：灯控冲突密度最高，必须重罚「图几秒」。

2.2 超速

  • 场景：城市道路、公路、高速；不同超速幅度。
  • 怎么走：守限速，恶劣天气再降（见 #speed）。
  • 不能怎么走：「跟流就没事」。
  • 为什么：动能与制动距离随速度上升。
  • 违规后果：分档处罚必须打开官方《记分管理办法》核对，本站不抄易过期数字。
  • 为何这样罚：幅度越大，致死致伤概率跃升。

2.3 酒驾 / 醉驾 / 毒驾

  • 场景：聚餐后、隔夜残留误判、「自认清醒」。
  • 怎么走：开车不饮酒；不确定就不开。
  • 不能怎么走：酒后短途、代驾前自己挪车。
  • 为什么：酒精/毒品损害反应与判断。
  • 违规后果：行政直至刑事；事故责任极重。详见《道交法》法律责任章。
  • 为何这样罚：一次失误可致死，必须零容忍。

2.4 肇事逃逸

  • 场景：碰撞后惊慌、想「私了却离开」。
  • 怎么走：停车警示、报警、保护现场、救助伤员（量力）。
  • 不能怎么走：驶离逃避。
  • 为什么：逃逸贻误抢救并破坏责任认定。
  • 违规后果：严惩；民刑风险叠加。
  • 为何这样罚：把「伤人后逃跑」的预期成本提到无法承受。

2.5 伪造变造证件号牌 / 使用伪造证

  • 场景：套牌、假证、故意遮挡号牌逃避查处等。
  • 怎么走：合法办证挂牌。
  • 不能怎么走：任何造假、买卖分、替考。
  • 为什么：摧毁整套监管与保险追责链条。
  • 违规后果：严惩并严重影响后续办证。
  • 为何这样罚：造假是系统性欺诈，不是「小聪明」。

3. 证件全周期（申领 → 实习 → 审验换证）

阶段怎么走不能怎么走依据入口

subject4 · 科目四：文明与应急（教材级）

科目四考「活下来、别害人」的决策。以下每个主题独立写满六问（禁止只留一行表）。

主题 A · 安全带与安全装置

  • 场景：城市短途、高速、后排乘员、有气囊车型、儿童乘车。
  • 怎么走：上车先系安全带（驾驶人与乘车人按规定）；儿童使用合格儿童安全座椅等约束装置；确认头枕等基本装置可用；气囊作为辅助保护。
  • 不能怎么走：短途/后排不系；用成人安全带错误固定婴幼儿；以为「有气囊就不用安全带」；故意拆除停用安全带提醒装置。
  • 为什么：碰撞在毫秒级发生，只有预先约束才能避免人体撞击内饰；气囊展开也需身体被安全带定位，否则可能加重伤害。
  • 违规后果：不按规定使用安全带可罚；事故中伤害显著更重，民事赔偿与责任评价更不利。
  • 为何这样罚：把「可预防的二次碰撞伤害」降下来，保护乘员也降低社会医疗成本。

主题 B · 紧急情况处置（爆胎、制动异常等）

  • 场景：高速或普通路突然爆胎、制动变软/失效征兆、转向异常。
  • 怎么走：双手握稳方向盘；平稳松油门；避免猛打方向；视情况轻柔制动或用发动机阻力降速（按车型与教练教导）；开启危险报警闪光灯；逐步驶离行车道至应急车道/路肩等安全处；按规定设置警示标志；人员转移到护栏外等安全位置（视环境）。
  • 不能怎么走：慌乱猛打方向；突然拉驻车致甩尾；停在行车道「先下车看一眼」；无警示夜间占道。
  • 为什么：突发载荷变化时，稳车与被后车看见优先于「立刻停死」；行车道暴露会招二次事故。
  • 违规后果：失当操作可致翻车/连环撞；占用行车道妨碍通行可能被查处；二次事故责任往往更重。
  • 为何这样罚 / 为何这样考：引导故障车尽快离开高暴露位置，保护后方高速接近的车辆。

主题 C · 文明礼让、禁停与应急车道

  • 场景：人行横道、拥堵加塞、公交站、禁停路段、高速公路应急车道。
  • 怎么走：横道减速礼让行人；按序通行不逼车；禁停路段不占；应急车道仅紧急情况使用（救援、故障按规定）。
  • 不能怎么走：鸣笛催行人；双闪当「合法违停」；把应急车道当超车道/出行车道。
  • 为什么：礼让保护无防护者；应急车道是生命通道。
  • 违规后果：不礼让、违停、违法占用应急车道可罚记分（档位查《记分管理办法》）；事故责任不利。
  • 为何这样罚：拥堵中抢行与占应急车道会系统性放大伤亡与延误救援。

主题 D · 恶劣天气与夜间

  • 场景：雨雾冰雪、低能见度、夜间会车/尾随、隧道出入口。
  • 怎么走：能见度差就减速、加大间距；会车改近光；按规定使用雾灯等；隧道提前开灯（见 #lights #speed）。
  • 不能怎么走：雾天远光散射；冰雪急刹急打；夜间一路远光。
  • 为什么：附着与视距下降时，原限速内也可能刹不住。
  • 违规后果：不当灯光与超速可罚；事故中「应预见而未预见」常不利。
  • 为何这样罚：恶劣天气是可预见风险，法律要求降速降风险而非硬冲。

主题 E · 高速公路安全

  • 场景：匝道汇入、多车道变道、车距、故障停车、应急车道。
  • 怎么走：加速车道提速后观察汇入；保持更大车距；变道灯→镜→盲区；故障时尽快到应急车道等规定位置并警示。
  • 不能怎么走：加速车道末端停车；连续穿插；非紧急占应急车道行驶。
  • 为什么：车速高，决策窗口短，错误不可逆。
  • 违规后果：相关违法可罚；高速事故动能大、后果重。
  • 为何这样罚：高速是「容错率极低」环境，必须用重罚维持间距与应急通道。

主题 F · 事故现场与救护常识

  • 场景：轻微刮擦到人员受伤。
  • 怎么走：开启危险报警闪光灯；人员转至安全位置；按规定设警示标志；报警；保护现场；在确保自身安全前提下呼叫专业救援，量力协助，避免二次伤害。
  • 不能怎么走：逃逸；全员站在行车道争论拍照；不懂装懂拖拽可能脊柱受伤者。
  • 为什么：二次事故与延误抢救造成的伤害往往超过一次碰撞。
  • 违规后果：逃逸严惩（行政/刑事风险）；破坏现场妨碍认定。
  • 为何这样罚：把「伤人后逃跑」变成不可承受的法律风险。

声明：本节救护仅为常识取向，不替代红十字/专业急救培训。

2. 六问（为何要分型）

  • 场景：报名选 C1/C2、练车、科目二/三考试、上路选车。
  • 怎么走：按准驾车型训练与应考；理论（灯线让行文明）两型同学。
  • 不能怎么走：C2 考生默写 C1 离合步骤当「标准答案」；C1 考生忽视离合导致溜车熄火仍怪「场地问题」；持不符准驾车型上路。
  • 为什么：传动控制方式不同 → 失误模式不同（熄火/溜车 vs 刹车控制）；但交通冲突规则相同。
  • 违规后果：考试项目操作不符车型 → 不合格；准驾不符上路 → 违法（见申领使用规定与道交法）。
  • 为何这样罚 / 分型：让培训考试匹配真实车辆，避免「会背不会开」；同时防止自动挡考生被错误离合知识干扰。

3. 题库与课内表述规范（给教练/写课）

  • 涉及离合、半联动、空挡起步：只进 C1 路径。
  • C2 课写：刹车控速、挡位 P/R/N/D、禁止出现「踩离合」。
