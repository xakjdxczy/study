1. 为什么要 PBR

结论：PBR 把「材质像什么」和「这一帧怎么打光」拆开；Phong 系常常是对着某一盏灯拧高光指数与颜色。

Phong 系PBR（微表面）
参数多为外观旋钮（shininess、specular 色）尽量对应物理直觉（粗糙度、F0、金属度）
换光常要重调才「好看」同一套材质在不同灯光下更可迁移
能量多项相加易「越加越亮」用 D/F/G 与归一约束能量直觉

「对着某灯拧参」的痛点：场景换 HDR、加平行光，高光块形状与亮度全变味。PBR 不保证自动好看，但材质常数含义稳定，灯光与 IBL 负责环境。

2. 渲染方程 → 反射方程

结论：出射光 = 半球上「BRDF × 入射光 × 余弦」的积分；实时把它拆成直接光解析项 + 环境近似。

反射形式（省略自发光）：

Lo(v) = ∫Ω fr(l, v) · Li(l) · (n·l) dωl
  • Lo(v)：沿观察方向 v 的出射辐亮度
  • fr：BRDF（单位立体角上的反射比例）
  • (n·l)：入射方向与宏观法线的余弦（斜射变弱）

本课焦点是镜面 BRDF fs（微表面 Cook-Torrance）；漫反射另计。

3. 微表面模型：统计小镜面

结论：宏观光滑表面由无数微观小镜面组成；只有法线朝向半角 h 的那些，才能把 l 反射到 v。

h = normalize(l + v)

4. Cook-Torrance：fs = DFG / (4(n·l)(n·v))

结论：三项各管一件事——有多少微面朝向 h（D）、反射多少（F）、互相挡住多少（G）；分母完成微面到宏观的量度变换。

fs = D(h) · F(v,h) · G(l,v,h) 4 · (n·l) · (n·v)

为何要分母 4(n·l)(n·v)？

  • 微面反射是对微面法线 h 定义的；渲染方程要对宏观 n 与方向 l、v 积分。
  • 从「绕 h 的立体角」变到「宏观方向」有雅可比因子，标准推导给出 4(n·l)(n·v)（或等价形式）。
  • 直观：少了它，余弦与微面密度会重复计数或量纲不对，高光随观察角行为会歪。

5. D：GGX 直觉与公式

结论：D 回答「有多少微面法线指向 h」；粗糙度越大，峰越矮越宽，高光越散。

常用 GGX（Trowbridge-Reitz），α 常取 roughness²：

DGGX(h) = α² π [ (n·h)² (α² − 1) + 1 ]² ，　α = roughness²

6. F：Fresnel / Schlick；金属 vs 非金属

结论：F 是「这一视角反射多少」；掠射角反射变强。Schlick 用一次幂次近似完整 Fresnel。

FSchlick = F0 + (1 − F0)(1 − (h·v))5
  • 非金属：F0 常由 IOR 推导，塑料常见 ~0.04；漫反射吃掉折射进表面再散射的部分。
  • 金属：导体几乎不「漫反射体色」；albedo 当作彩色 F0。

7. G：遮挡与阴影（Smith / Schlick-GGX）

结论：粗糙表面的微面会互相挡住入射（阴影）与出射（遮挡）；G 把「看得见」的比例折进去。

  • Smith 形式常见：G = G1(l) · G1(v)，分别处理光侧与眼侧。
  • Schlick-GGX：用与粗糙度相关的 k，把 G1 写成解析式，避免数值积分。
  • 直觉：越擦边、越粗糙，G 压得越狠——否则 DF 会让掠射高光爆炸。
G1(x) ≈ (n·x) / [ (n·x)(1 − k) + k ]　（Schlick-GGX 一类写法；k 由 α 导出）

8. 漫反射项 + metallic 如何拆能量

结论：metallic 工作流用一张 albedo + 金属度，在「漫射体色」与「镜面 F₀」之间插值，避免能量双计。

  • metallic = 0：漫反射用 albedo；镜面 F0 用低介电常数（或 IOR）。
  • metallic = 1：漫反射 → 0；albedo 作为 F0。
  • 常见写法：kd = (1 − F)(1 − metallic)，再乘 Lambertian albedo/π。
L ≈ (kd · albedo / π + fs) · Li · (n·l)　（单方向光示意）

9. 实时实现：解析近似，不是逐微面模拟

结论：游戏里算的是闭式 GGX + Schlick F + Smith-G，再加点光与 IBL；不是几何级画出每个小镜面。

  • 直接光：解析 BRDF × 灯光 × 阴影。
  • 环境：分裂和 / 预积分 LUT（如 DFG LUT）近似半球积分。
  • 常见组合：GGX + Schlick Fresnel + Schlick-GGX Smith（与具体引擎命名可能略异，以文档为准）。

10. 小结

  • PBR 镜面核心：微表面统计 + Cook-Torrance DFG / 4(n·l)(n·v)。
  • D 管高光形状，F 管反射比与金属色，G 管可见性。
  • metallic 拆漫射与镜面能量；实时用解析近似 + IBL，不是逐微面仿真。
