# 一年级数学 · 单元精讲：认识图形（立体初步）

> 目标：辨认长方体、正方体、圆柱、球；能在生活中找到例子；会初步分类。

## 知识点
1. **长方体**：像牙膏盒、字典；有平平的面。
2. **正方体**：像魔方；六个面一样方。
3. **圆柱**：像易拉罐、茶叶罐；能直立，有的能滚动。
4. **球**：像皮球；怎么放都会滚。
5. **分类**：会滚的 / 不会滚的；能叠高的 / 不能叠高的。

## 例题
**例 1** 足球属于哪一种？  
**答**：球。

**例 2** 骰子更像正方体还是圆柱？  
**答**：正方体。

**例 3** 哪些可以叠得比较稳？长方体、正方体、球  
**答**：长方体、正方体（球不容易叠稳）。

## 练习
1. 连线：牙膏盒 / 皮球 / 积木 / 水杯（圆柱形）→ 对应形状。
2. 判断：所有会滚的都是球。（×，圆柱也能滚）
3. 家里找一找：各找出 1 个长方体和 1 个圆柱。
4. 说一说：正方体和长方体哪里像、哪里不像。
5. 动手：用橡皮泥搓一个球、一个近似圆柱。

## 说明
本单元重在「辨认与感知」，不要求计算表面积。
