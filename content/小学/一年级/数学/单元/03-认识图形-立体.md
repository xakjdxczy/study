# 找一找立体朋友

## 今天学什么
认识四位朋友：长方体、正方体、圆柱、球。  
在家里把它们找出来！

## 跟我做
1. 摸一摸盒子：平平的面 → 可能是长方体。
2. 看魔方：六个面一样方 → 正方体。
3. 看易拉罐：圆圆站着 → 圆柱。
4. 看皮球：滚来滚去 → 球。

## 小知识
- 长方体：像牙膏盒、书本。
- 正方体：像骰子、小积木。
- 圆柱：像茶叶罐、短水管。
- 球：像皮球；不容易叠高。

## 练一练
1. 足球是哪一种？  
   **答案：球**
2. 牙膏盒更像什么？  
   **答案：长方体**
3. 判断：会滚的一定是球。（对 / 不对）  
   **答案：不对，圆柱也会滚**
4. 哪些更容易叠高？长方体 / 球  
   **答案：长方体**
5. 回家找出：1 个圆柱、1 个正方体。
