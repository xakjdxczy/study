# 小学课程资料库

面向小学 1–6 年级的课程大纲与学习资料。现有站点「阳光英语 · 五年级」仍在仓库根目录；本目录用于扩展全科内容，后续可接到网页导航。

## 学科（按常见课标）

| 学科 | 年级范围 | 说明 |
| --- | --- | --- |
| 语文 | 1–6 | 识字、阅读、习作、口语交际 |
| 数学 | 1–6 | 数与代数、图形几何、统计概率、综合实践 |
| 英语 | 3–6（部分地区 1–2 有启蒙） | 听说读写、语音词汇语法 |
| 道德与法治 | 1–6 | 品德与法治 |
| 科学 | 1–6（或 3–6，按地区） | 物质、生命、地球与宇宙、技术与工程 |
| 体育与健康 | 1–6 | 体能、技能、健康知识 |
| 音乐 | 1–6 | 演唱、欣赏、识谱 |
| 美术 | 1–6 | 造型、设计、欣赏 |

## 目录约定

```
content/小学/<年级>/<学科>/
  大纲.md      # 学期知识点总览
  单元/        # 按单元讲解与例题（逐步填充）
```
