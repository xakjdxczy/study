# 图形渲染网页课 · 写法标准（引擎 / 图形向）

**总目标**：读者能自己点开——先抓住结论，再跟推导，最后用自测题检验迁移；面向引擎与实时渲染学习者，不是 K-12。

与驾照课同级产品门槛；与小学课不同：不用幼教口吻，允许公式与符号，但必须**可读、可滚、可练**。

## 硬标准
1. **先结论后展开**：每节开头用一两句讲清「这一项干什么」；再给公式与推导直觉。
2. **公式可读**：长式用 `.formula` 横向滚动；禁止撑破导航。可用 HTML/Unicode/SVG，若全站日后统一 KaTeX 再迁移。
3. **图文并茂**：微表面半球、D/F/G 角色、金属/非金属能量拆分等关键对象必须有内联 SVG（不依赖外链 CDN）。
4. **能练**：自测题可点选；选后立刻写清原因（对为什么对、错为什么错）。
5. **题解锚点**：每题反馈附「详见：…」链到本课或知识总览稳定 `#锚点`（见 `content/经验-题解锚点.md`）。无章先补锚点再出题。
6. **结构建议**：`动机` → `方程直觉` → `模型与公式` → `分项 D/F/G` → `工作流` → `实时近似` → `小结` → `自测`
7. **边界**：注明「实时实现多为解析近似，非逐微面模拟」；不编造引擎专有黑盒参数。
