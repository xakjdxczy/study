# 驾照网页课 · 设计与审核规则（成人备考）

**总目标**：考生能自己点开——看懂考点、练会易错题、过关后再往下；C1/C2 该分的分开，该共用的共用。

与小学课不同：不用幼教口吻，但保留电子优势。

## 目录约定
```
驾照/
  科目一/          # C1/C2 共用
  科目二-C1/ 科目二-C2/
  科目三-C1/ 科目三-C2/
  科目四/          # 共用
  考前清单/
content/驾照/      # Markdown 源与题库草稿
```

## 硬标准
1. **短屏**：一屏一个考点或一组题；先结论后展开。
2. **能练**：判断 / 单选 / 多选（标清题型）；选错立刻讲依据（规章要点，不编造条文号若不确定）。
3. **图文**：标志、标线、灯光、档位必须有图或示意；禁止纯文字描述「那个蓝牌」。
4. **分型**：涉及离合 / 手动档位的只放 C1；C2 不出现无关注合器操作。
5. **迁移**：练习与过关换题干/换情境，不背同一道原题。
6. **边界**：各地场地项目、学时、预约规则写「以本地车管所 / 驾校为准」；不提供替考、作弊建议。
7. **结构**：`要点` → `图示/动画或步骤` → `练一练` → `过关` → `小结口诀`

## 题解 + 规则总览（强制）

1. **每题必有原因**：选后反馈写清依据与易错点，禁止只显示「正确/错误」。
2. **规则总览**：维护 `驾照/规则总览/index.html`（源稿 `content/驾照/规则总览.md`），按主题分章、稳定 `#锚点`。
3. **题链总览**：反馈区必须有「详见：…」链到对应锚点。
4. 新考点先写入总览再出题；总览注明「地方细则以车管所/驾校为准」，不编造条文号。

模式说明：`content/经验-题解锚点.md`。

## 规则总览深度（强制）

`驾照/规则总览/` 必须按 `content/驾照/规则总览-深度标准.md` 写到「教材级」：
六问齐全；信号灯章须覆盖多路口形态 × 多灯型 × 多车道；处罚与理由写清并标注地方/现行法规可能调整。
