# 规则总览 · 深度标准（全面学习强制）

总览不是提纲，必须能**单独当教材读懂怎么开、为什么、违规会怎样**。课内短讲 + 总览深学。

---

## 一、通用：每一考点六问（缺一打回）

1. **场景**：穷举考试与上路高频形态（路口/路况/车型情境）
2. **怎么走**：正确步骤与观察顺序
3. **不能怎么走**：禁止与易错动作
4. **为什么**：安全与秩序逻辑（不背干口诀）
5. **违规后果**：常见处罚/记分/事故责任倾向
6. **为何这样罚**：惩戒目的

另加硬性要求：

7. **权威依据**：本节涉及的法律/规章/标准，必须附**可点击的官方来源链接**（见第三节），写清文件名；能落到条款的尽量标条款主题（如「信号灯通行」「记分」），**不编造已废止条文号**；分值/罚款写「常见口径」并注明以现行文本与当地执行为准。

---

## 二、举一反三：各章必须穷举的「形态矩阵」

写法对齐信号灯样板：**形态表 × 组合怎么走 × 禁走 × 罚则与罚因 × 官方链接**。

### `#signals` 信号灯与交警手势（样板，已达标口径）

| 维度 | 至少覆盖 |
|------|----------|
| 路口 | 十字、丁字、斜交、五叉/多路、环岛接灯、进口单排/双排/三排及以上、有无专用转向道 |
| 灯具 | 圆形、箭头、混合、横排、竖排、车道信号灯、黄闪、人行灯与车灯关系 |
| 组合 | 路口×灯色/箭头×本车道：直行/左右转可否、待行、让行、停止线 |
| 优先 | 交警手势优先于灯 |
| 罚则 | 闯红灯、抢黄灯、不按导向、红灯右转未让行、拒手势、堵路口 |
| 依据 | 《道交法》《实施条例》信号灯/路口通行；《记分办法》对应档 |

### `#signs` 标志

| 维度 | 至少覆盖 |
|------|----------|
| 大类 | 禁令、指示、警告、指路（及辅助标志） |
| 外形编码 | 红圈/斜杠、蓝底、黄三角等「第一眼识别」 |
| 高频个案 | 禁止驶入/通行、禁止转向、禁止鸣喇叭、限速、解除限速、停车让行、减速让行、禁止超车、禁止停车/长停、单向、公交专用、人行横道、注意行人/儿童/危险 |
| 组合 | 标志+辅助牌（时间/车种/方向）；标志与标线冲突时的处理原则（以现场交警与法规适用为准，写清「不得自行脑补」） |
| 罚则 | 闯禁令、违限速、违停等常见后果与为何罚 |
| 依据 | 《道交法》遵章通行；标志国标 GB 5768 系列（官方标准公开页）；实施条例相关 |

### `#markings` 道路标线

| 维度 | 至少覆盖 |
|------|----------|
| 线型 | 白虚/白实、黄虚/黄实、单黄/双黄、导流线、停止线、让行线、人行横道、导向箭头、网状线、边缘线、公交专用线 |
| 场景 | 路段变道、路口导向、对向分隔、导流岛、待行区（若有） |
| 组合 | 标线×标志×灯（例：导向箭头+实线+红灯） |
| 罚则 | 轧实线、轧导流、越停止线、不按导向 |
| 依据 | 实施条例车道/标线通行；GB 5768；记分办法相关项 |

### `#lights` 灯光与喇叭

| 维度 | 至少覆盖 |
|------|----------|
| 灯种 | 近光、远光、示廓/位置、雾灯、转向、危险报警、倒车灯 |
| 场景 | 夜间路灯良好/不良、会车、尾随、超车示意、隧道、雨雾雪沙尘、故障临时停车、路口示意 |
| 喇叭 | 允许示意 vs 禁鸣区/夜间扰民 |
| 罚则 | 滥用远光、不按规定使用灯光、随意鸣喇叭 |
| 依据 | 实施条例灯光条款；道交法安全文明相关 |

### `#speed` 速度、跟车、超车、会车

| 维度 | 至少覆盖 |
|------|----------|
| 道路 | 城市道路、公路、高速；同向 1/2/3+ 车道 |
| 天气 | 晴、雨雾冰雪、低能见度（含高速分档能见度若适用） |
| 行为 | 限速遵守、安全车距、不得超车清单、会车靠右与让行 |
| 罚则 | 超速分档、违法超车、低能见度违法 |
| 依据 | 实施条例车速车距超车会车；高速专章；记分办法超速档 |

### `#yield` 路口通行与让行（无灯/灯控外）

| 维度 | 至少覆盖 |
|------|----------|
| 路口 | 无灯十字/丁字/多路、环岛、支路汇入干路 |
| 规则 | 转弯让直行、右转让左转（冲突时）、让行标志/标线、行人优先场景 |
| 与灯关系 | 有灯看 `#signals`；无灯本节；手势优先 |
| 罚则 | 不让行、抢行导致事故的责任倾向 |
| 依据 | 道交法/实施条例路口通行与礼让 |

### `#penalty` 处罚、记分与证件

| 维度 | 至少覆盖 |
|------|----------|
| 制度 | 记分周期、满分学习考试、罚款与其他处罚类型（吊销/拘留等只作严重情形提示） |
| 高频违法 | 酒驾醉驾、逃逸、伪造变造证件号牌、闯红灯、超速等（分值以《记分办法》原文为准，**表格摘录必须可回溯链接**） |
| 证件 | 申领条件概要、实习期、审验换证（细节以公安部令为准） |
| 禁止 | 替考、作弊、买卖分 |
| 依据 | 《记分办法》《驾驶证申领和使用规定》《道交法》法律责任章 |

### `#subject2` 科目二

| 维度 | 至少覆盖 |
|------|----------|
| 项目 | 倒库、坡起、侧方、曲线、直角（以大纲与本地考场为准列出） |
| 分型 | C1 离合/半联动；C2 无离合 |
| 每项六问 | 步骤、扣分红线、为何扣、场地差异免责 |
| 依据 | 《驾驶证申领和使用规定》考试相关；本地考场规则链到「以车管所/驾校通知为准」 |

### `#subject3` 科目三

| 维度 | 至少覆盖 |
|------|----------|
| 项目 | 上车起步、直线、变道、加减挡、路口/横道/学校、靠边、掉头等 |
| 灯光口令 | 与 `#lights` `#signals` 交叉引用 |
| 分型 | C1/C2 操作差 |
| 依据 | 同上考试规定 + 道交法通行规则 |

### `#subject4` 科目四 / 安全文明

| 维度 | 至少覆盖 |
|------|----------|
| 主题 | 安全带与安全装置、紧急情况、文明礼让与禁停、恶劣天气夜间、高速、事故现场与救护 |
| 每主题六问 | 含「做错的瞬时风险」与违法后果 |
| 依据 | 道交法/实施条例对应章；记分办法；救护仅作常识不替代专业培训 |

### `#exam-prep` 考前清单

| 维度 | 至少覆盖 |
|------|----------|
| 材料/流程/状态 | 证件、通知、身体精神、禁作弊 |
| 依据 | 申领使用规定；本地车管所通知（官方预约/公示入口能链则链） |

### `#c1c2` C1/C2

| 维度 | 至少覆盖 |
|------|----------|
| 对照表 | 离合、挡位、考试项目表述差异 |
| 共用 | 灯线让行文明不因车型而变 |
| 依据 | 申领使用规定准驾车型 |

**验收口诀**：每一章都能画出一张「形态表」，且每条高频违法能点到官方依据链接。

## 三、权威官方信息（必须附链接）

总览文首设「权威依据导航」；各章末设「本节依据」列表。优先顺序：

| 文件 | 官方入口（写入总览，定期校对） |
|------|--------------------------------|
| 《中华人民共和国道路交通安全法》（含修正） | 中国政府网相关公布/人大网文本；地方交管转载的 2021 修订全文可作阅读入口，如北京市公安交管局转载页 |
| 《道路交通安全法实施条例》 | https://www.gov.cn/zhengce/zhengceku/2008-03/28/content_3745.htm |
| 《机动车驾驶证申领和使用规定》（公安部令） | https://www.gov.cn/gongbao/content/2022/content_5679696.htm |
| 《道路交通安全违法行为记分管理办法》 | https://www.gov.cn/zhengce/2021-12/27/content_5712880.htm |
| 道路交通标志和标线等国家标准 | 国家标准全文公开系统 / 国务院标准公开渠道（写清标准号 GB 5768 等，链到官方公开页，勿链来路不明搬运站） |

写作规则：

- 外链 `target="_blank" rel="noopener"`；标注「官方」。
- 禁止只写「依法处罚」而不给文件入口。
- 地方细则：写「以本地车管所为准」，有官网办事页可附。
- leader 抽查：随机点开链接须为政府域名或官方标准库。

## 四、与题解锚点

总览达成本文件粒度后，课内「详见」才算合格。总览仍是提纲、或无官方链接 → **整批评回**。

## 五、图文并茂（总览强制）

总览教材级 **包含插图**，不是「字多就行」。

每章至少：
- `#signs`：三类外形对照图 + 高频禁令/指示/警告各一例示意
- `#markings`：白虚/白实/黄线/双黄/停止线/人行横道/导向箭头示意
- `#signals`：圆形灯、箭头灯、混合灯板、横竖排；十字/丁字简图；单双三排车道示意
- `#lights`：近光/远光/雾灯/转向/危险报警示意
- `#speed`/`#yield`：超车会车/环岛/让行冲突简图
- `#subject2`/`#subject3`：场地俯视或上路关键动作分步图
- 其余章：与考点匹配的示意图，禁止整章纯文字

实现可用内联 SVG / CSS 示意 / 清晰 emoji 组合；外形必须正确。无图 = 该章未达标。
