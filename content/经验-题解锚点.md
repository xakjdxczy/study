# 经验模式 · 题解 + 总文档锚点（全站可复用）

**来源**：学驾照题反馈「问题不全面、缺原因」→ 要求每题讲清原因，并链到一份最全规则总文档。

## 模式是什么

1. **即时题解**：选对/选错后立刻给完整原因（为什么对、错项错在哪），不甩「正确」两字。
2. **总文档**：另建一份系统、全面、可检索的规则/知识总览（按主题分章，带稳定锚点 `#id`）。
3. **题 → 文档**：每题反馈区附「详见：xxx」链接，跳到总文档对应章节，需要时可深读，不打断刷题节奏。

## 优点（后续项目可套用）

| 优点 | 说明 |
|------|------|
| 刷题不打断 | 短反馈够过关；详解按需点开 |
| 不重复堆文 | 课内短讲，权威细节集中在总文档，改一处全站受益 |
| 可追溯 | 锚点固定，题与规则一一对应，验收可抽查 |
| 成体系 | 总文档补「全面」；课补「练」；两者合起来才是产品 |
| 可迁移 | 小学/任何题库课同样适用：例题错因 + 链到年级/学科知识总览 |

## 落地约定

- 总文档路径示例：`驾照/规则总览/index.html`（或 Markdown 同源 `content/驾照/规则总览.md`）
- 锚点命名：`#sign-ban`、`#yield-uncontrolled` 等英文短 id，稳定不改
- 反馈模板：`原因：…。` + `<a href="../../规则总览/#锚点">详见：章节名</a>`
- 无对应章节时先补总文档，再挂链；禁止空链或「敬请期待」死链

## 验收（leader）

- [ ] 每题有实质原因（对/错都讲清）
- [ ] 每题有可用的总文档锚点链接
- [ ] 总文档该章内容覆盖该题考点，非空壳
- [ ] 小学等栏目若出题，同样检查是否适用本模式

**判断口诀**：只要「有题可练」→ 默认启用「题解 + 总文档锚点」。
