# 学习站 · 工程与体验验收标准（全员强制）

配合 `content/产品标准.md`。内容再好，工程不达标也不能宣称上线。

---

## 一、导航与信息架构（本次重点）

1. **全局可达**：任意内容页必须能回到 **站点首页**（`/study/`）与 **本栏目首页**（如 `/study/驾照/`、`/study/小学/`）。
2. **层级返回**：课内页须有返回 **上一级目录**（科目/年级/学科）。
3. **位置可见**：用面包屑或顶栏标明：首页 / 栏目 / 科目（或年级）/ 当前课。
4. **无死链**：入口卡片要么可点开完整课，要么明确「待上线」且不可点进空壳。
5. **一致**：全站顶栏样式、文案、顺序统一；禁止有的页只有「上一屏」、找不到站级出口。

实现：引入全站 `assets/site-nav.css` + `assets/site-nav.js`（自动注入顶栏）。新课必须包含这两份资源。

---

## 二、布局与多端

1. 主内容最大宽约 720–960px，居中；手机单列可读。
2. 按钮可点区域足够大（约 ≥44px 高），避免贴边难点。
3. 禁止横向撑破（长公式/大图可滚动，但导航不丢）。
4. 安全区：顶栏 fixed/sticky 时，正文留出顶距，不被挡住。

---

## 三、交互与状态

1. 课内「上一屏 / 下一步」与站级「首页 / 栏目」职责分离，二者都要有。
2. 禁用按钮有视觉反馈；过关锁定逻辑不得卡死无法返回目录。
3. 外链（若有）新标签打开并说明；站内只用相对或 `/study/` 根路径。
4. 加载失败/空数据有简短提示（后续有 API 时适用）。

---

## 四、视觉与品牌一致

1. 同栏目色板、圆角、字体层级一致（可复用栏目 `styles.css`）。
2. 课内若内联样式，顶栏仍用全站 `site-nav`，不得各自发明一套全局导航。
3. 图标/emoji 表意清晰；装饰不挡正文。

---

## 五、无障碍与可读

1. 重要控件有可见文字，不只靠颜色。
2. 图示有 `aria-label` 或旁注（标志、灯光等）。
3. 点读按钮文案统一（如「读给我听」）。
4. 对比度大致可读（正文与背景分明）。

---

## 六、性能与工程卫生

1. 单课尽量单 HTML + 必要 CSS/JS；大资源压缩。
2. 不提交密钥、`.env`、本机绝对路径。
3. `git` 直推或 PR 均可，但 **禁止 Cloud Agent 写课**（产品协作规则）。
4. 新增目录同步更新栏目 `index.html` 与 `大纲.md`。

---

## 七、发布与验收（leader）

合并/同步前勾选：

- [ ] 顶栏：首页 + 栏目 + 上级（或等价面包屑）
- [ ] 栏目入口无死链空壳
- [ ] 手机宽度抽查通过
- [ ] 课内练习/过关仍可用，返回目录不丢
- [ ] 产品标准（专业/体系/质量）同时通过

未勾满 → **打回**，写明工程改点。
