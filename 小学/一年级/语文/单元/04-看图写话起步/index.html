一年级语文 · 看图写话起步

目标：看图说清楚「谁、在哪里、做什么」；能写 1–2 句通顺的话。

知识点

  1. 观察顺序：先整体后局部；人物 → 动作 → 表情 → 环境。
  2. 说话公式：谁 + 在哪里 + 做什么（+ 心情）。
  3. 写话要求：句子完整；用句号；不会的字可先用拼音顶上。
  4. 常用词：有、在、看、玩、笑、跑、说。

例题

图意（口述）：草地上，小朋友放风筝。

例句：小朋友在草地上放风筝。

升级句：阳光明媚，小朋友高兴地在草地上放风筝。

练习

  1. 看图（自备一张公园图）说三句话：谁？在哪？干什么？
  2. 把下面词语排成一句话：小鸟 / 树上 / 唱歌（小鸟在树上唱歌。）
  3. 改病句：小明跑。（补成完整句，如：小明在操场上跑。）
  4. 写话：用「我看见……」写一句。
  5. 互评：和家长交换读，听句子通不通。

家长小提示

先说后写；写完读一遍，问「缺了谁或什么动作吗」。
